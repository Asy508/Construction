## Installation Method
1. Method of return air columns
    1. Sandwich panel vertically on the floor
    2. Sandwich panel vertically on the raised floor
    3. Sandwich panel vertically on the gantry frame

2. Method of reinforment
    1. Five-point support (center point)
    2. Six-point support (use beam)

3. Method edge finishing
    1. Angle bar
    2. Diagonal brace

4. Method electrostatic earthing
    1. use 4mm2 bare copper wire
    2. interconnect to pedestal head
    3. 1.2m distance
    4. copper wire connected to electrostatic earthing box

5. Method expansion joint crossover

The specific engineering process used to build a raised access floor over a structural building gap without using standard rigid connections.

6. Method Stair tread
   During raised floor installation, the manufacturer should first reserve the stair tread installation position at the doorway according to the client’s specified tread dimensions. Once the stair treads are installed, edge finishing should be applied using stainless steel or galvanized sheet. After the edge finishing is completed, PVC floor tiles should be applied, integrating the stair treads seamlessly with the raised floor system.
