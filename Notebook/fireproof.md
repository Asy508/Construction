# Fireproof Sealing Installation Requirements

## Regulations
1. **GB50016-201** =>Code for Fire Protection in Building Design
2. **CECS154:2003** =>Technical cod efor application of building Fireproof Sealing
3. **GB23864-2009** =>Fireproff Sealing Materials
4. **GB50217-2018** => Code for design of cables in electric power engineering

## Type of Fireproof Materials for Pipelines

The purpose is to seal the gaps between wall,floor, or opening surrounding.

1. Concrete (Cement)
2. Firestop putty
3. Fire-resistance board
4. Firestop sealant
